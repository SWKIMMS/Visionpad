# 사운드 통합 검증 결과

이 문서는 2026-10-14 초기 효과음 통합 검증 기록이다. 후속 음성 조절/시연 준비는 `DEMO_READY.md`, 최신 게임플레이 개발 결과는 `GAMEPLAY_UPDATE.md`, 현재 설치 및 전달 안내는 `TEAM_HANDOFF.md`를 참고한다.

2026년 10월 14일, 현재 Mac의 `codex/audio-tts-npc` 로컬 변경을 검증했다. 자동 검사 83개가 통과했고 실제 브라우저에서 작업 중 지도 전환과 일시정지·재개를 확인했다. 사용자 게임의 진행과 저장은 이번 회차에서 변경하지 않았다.

## 이번에 수정한 동작

| 상황 | 수정 후 동작 |
|---|---|
| 작업 중 다른 페이지로 이동 | 이전 작업음, 목표 통과음, 거래음과 합성음 및 늦은 로드를 취소한다. 새 화면의 이동·입장음은 재생한다. |
| 돌을 부순 직후 광산에서 나감 | 늦게 완료된 파괴 녹음 뒤에 옛 획득 안내나 희귀 보상음이 시작되지 않는다. |
| 뒤로가기 응답에 발걸음 녹음이 있음 | 발걸음과 메뉴 합성음을 중복 재생하지 않는다. |
| 음원 다운로드나 디코딩이 일시적으로 실패 | 실패를 영구 저장하지 않는다. 기본 1초 뒤 이후 행동 또는 상태 갱신에서 다시 시도한다. 지나간 효과음은 재생하지 않는다. |
| 배경음 최초 로드 실패 | 이후 상태 갱신에서 현재 화면의 배경음을 복구할 수 있다. |

수면 녹음은 기존처럼 다음 날까지 끝까지 이어진다. 일시정지, 음소거와 창 이탈은 수면을 포함한 소리를 중단한다. 게임의 비용, 성장, 보상 확률과 원본 MP3는 이번 수정으로 바꾸지 않았다.

## 게임 흐름 검사

`tools/audio_flow.py`는 실제 `GameEngine`에 포인터 누르기·드래그·떼기와 메뉴 명령을 전달한다. 총 155건의 입력, 9건의 시간 갱신과 초기 상태 1건으로 **응답 165건**을 기록했다.

| 구간 | 확인한 결과 |
|---|---|
| 농사 | 토마토 심기, 물과 비료, 수면 후 성장, 수확과 완료음 |
| 요리 | 실제 자르기와 젓기 경로 완료, 스튜 생성과 완료음 |
| NPC와 거래 | Rowan 인사와 농사 조언, 상점 이동, 작물 판매, 곡괭이와 낚싯대 구매 |
| 채굴 | 실제 타격으로 돌 파괴, 다이아몬드 획득과 지연 안내 |
| 낚시 | 희귀 획득의 splash/shine, 유효한 낚시의 실패음 |
| 제어와 저장 | 일시정지·재개, 저장·로드 후 재화·시간·날짜·화면·대화 보존 |

검사는 임시 저장 폴더와 테스트 엔진을 쓴다. 흐름을 빠르게 연결하기 위해 시작 골드만 500으로 두고 단조 시계를 앞당겼으며, 희귀 보상과 실패 분기에서는 난수 결과를 고정했다. 실제 플레이의 난도, 체감 대기 시간이나 확률을 측정한 검사는 아니다. 사용자 게임을 불러오지 않는다.

기록은 `output/audio/integration-flow.json`에 생성되며 Git에서 제외한다. Node 통합 검사는 이 실제 엔진 응답을 가짜 Web Audio 노드에 순서대로 전달해 재생·취소와 남은 반복음을 확인한다. 실시간 브라우저에서 전체 165개 응답을 모두 조작하거나 실제 음질을 평가했다는 의미는 아니다.

## 실행한 검사

```bash
.venv/bin/python -m unittest test_speech test_fishing test_sound_events test_audio_flow -q
node --test test_speech.cjs test_fishing_audio.cjs test_effects.cjs test_audio_integration.cjs test_hardware.mjs
.venv/bin/python tools/audio_flow.py
```

Python 29개, Node 54개로 **총 83개 통과**다. 통합 검사에서 화면 이동 시 늦은 소리 취소, 채굴 안내 취소, 수면 녹음 보존, 뒤로가기 중복 방지와 음원 실패 복구를 재현했다. 새 테스트는 `test_audio_flow.py`, `test_audio_integration.cjs`에 있다.

## 브라우저 확인

`tools/audio_integration_lab.py`를 8001번 포트의 별도 프로세스로 실행했다. 임시 진행의 물 주기 장면에서 Space로 누른 상태를 만들고, 소리 상태 `Watering`을 확인했다. F1 지도 전환 후 `Task and reward sounds ready`로 바뀌었고 농장 복귀, F4 일시정지·재개와 음성 재생 상태 `Speaking`을 확인했다. 오류·경고 로그는 없었다.

화면은 `output/audio/integration-check.jpg`다. 상단의 `INTEGRATION TEST · SEPARATE PROGRESS` 문구로 실제 진행과 구분한다. 검증 뒤 이 탭과 8001번 서버는 종료했다. 8000번 사용자 서버는 재시작하거나 조작하지 않았다.

같은 검사를 다시 열려면 다음 명령으로 실행한 뒤 `http://127.0.0.1:8001/`에 접속한다. 시작 장면은 테스트용 토마토 물 주기이며, 서버를 종료하면 해당 임시 진행은 삭제된다.

```bash
.venv/bin/python tools/audio_integration_lab.py
```

## 남은 확인

소프트웨어에서 동작과 취소를 검증했다. 실제 게임에서 효과음과 대사가 함께 들릴 때의 균형, 세부 발음, 스테레오 헤드폰의 앞뒤·거리감, 물리적인 창 전환 중 청취, 다른 PC와 실물 Dot Pad 사용성은 별도 확인이 필요하다. 다음 확인은 `LISTENING_CHECK.md` 순서로 진행한다. 첫 음성에 대한 기존의 긍정적인 사용자 평가를 새 혼합과 모든 방향감에 대한 승인으로 확대하지 않는다.

이 초기 기록 이후의 공유 버전, 최신 검증과 실행 방법은 `TEAM_HANDOFF.md`를 참고한다.
