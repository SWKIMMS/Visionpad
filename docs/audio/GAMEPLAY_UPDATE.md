# 게임플레이 음성·NPC·목표음 개발 결과

2026년 10월 18일, 음성 대기열·최근 행동 반응·농사와 채굴 목표음을 구현했다. 팀 main `3728f76`의 NPC 퀘스트·요일별 거래·클릭 매핑·작업 위치음과 통합했으며, 음성 작업에서 보상/시간/확률을 추가로 변경하지 않았다. 전체 변경과 현재 검증은 `TEAM_HANDOFF.md`에 정리했다.

## 빠른 조작에서 음성이 밀리는 문제

`speech_queue.py`와 비동기 음성 API를 연결했다. 같은 브라우저에서 새 안내가 오면 오래된 대기 요청은 Piper에 넘기지 않는다. 행동 결과와 대화는 다른 탐색 안내 및 시연 사전 생성보다 먼저 처리한다. 브라우저에서 중지·음소거·창 이탈·장면 이동을 할 때 서버에도 취소 순서를 전달한다.

- 요청의 `client_id`, `sequence`, `priority`로 브라우저별 최신 안내를 구분한다. 늦게 도착한 취소가 새 안내를 취소하지 않는다.
- 연결이 끊긴 요청도 대기열에서 제거한다. 이미 실행 중인 합성 한 건은 안전하게 끝내고 캐시로 남길 수 있지만, 취소된 요청의 음원은 전달하거나 재생하지 않는다. 이 한 건의 실행 시간을 강제로 없앤 것은 아니다.
- 대기열은 64개로 제한한다. 초과하면 429와 다시 듣기 안내를 반환한다. 오래된 요청은 204, 기존 오류는 422/503으로 처리한다.
- 기존 `text/profile/rate` 호출은 그대로 사용할 수 있다. 사전 생성 도구는 `background` 우선순위를 사용한다.

느린 합성을 재현한 검사에서 오래된 탐색 30건은 합성기에 전달되지 않았고 현재 결과만 처리됐다. 다른 브라우저의 행동 결과도 탐색/사전 생성보다 먼저 처리됐다. 실제 HTTP에서도 취소/옛 요청 204, 새 요청 200과 정상 WAV, 잘못된 우선순위 422, 기존 호출 200을 확인했다. 기록은 `output/audio/gameplay-api-check.json`이다.

## 최근 행동에 반응하는 Rowan

실제 수확·일반/생선 요리 완성·낚시 획득/무획득·채굴·곡괭이/낚싯대 파괴에서 최근 행동을 기록한다. 다음에 Rowan에게 말을 걸면 퀘스트 대사 또는 상점 조언의 인사 뒤에 해당 반응을 한 번 덧붙인다. 예: `Your first harvest! You can sell your Tomato here or use it in the kitchen.`

반응은 게임에서 확정된 아이템명과 결과를 사용한다. 실제로 성공하지 못한 행동을 성공으로 기록하지 않는다. 대화는 시간이나 재화를 추가 소비하지 않는다. 가장 최근 행동 한 건을 반영하며, 모든 과거 성취를 차례로 읽는 대기열은 아니다.

새 게임에서는 첫 수확·첫 요리·첫 낚시·첫 광물 획득의 반응을 구분한다. 기존 저장에는 이전 행동 이력이 없으므로 ‘처음’이라고 단정하지 않고 일반 반응을 쓴다. 행동 수, 최근 행동과 이미 들은 반응은 저장/로드에 포함된다. 현재 대사의 다시 듣기는 그대로 지원한다.

## 농사·채굴의 소리 안내

**Target cues on/off**로 물·비료·수확·광산의 새 목표음을 조절한다. 일반 Sound on/off 및 Sound volume과도 함께 동작한다. 설정은 현재 페이지 세션에서 유지하며 새로고침하면 켜진다. 이 버튼은 낚시 물소리를 끄지 않는다.

- 아직 끝내지 않은 가장 가까운 목표 쪽에서 짧은 HRTF 방향음이 들린다. 포인터 이동을 바로 반영하고 목표 사이 경계에서 소리가 과도하게 바뀌지 않게 한다.
- 가까워질수록 음이 조금 높아지고 간격이 짧아진다. 물·비료·수확·광산은 기본 음높이가 다르다.
- 완료한 농사 목표와 부순 돌은 안내 대상에서 즉시 빠진다. 목표의 숫자 좌표를 말로 읽지는 않는다.
- 농사 목표 통과음은 진행에 따라 조금 높아지고, 돌의 첫 번째/두 번째 타격음도 진행에 따라 높아진다. 원본 녹음은 수정하지 않았다. 요리 통과음과 기존 낚시 HRTF/게인은 유지한다.
- 일시정지, 밤, 수면, 화면 이동, 음소거와 창 이탈에서 목표음을 중단한다. 복귀할 때 현재 화면의 목표 안내는 복구하되 이전 작업음과 보상음을 다시 재생하지 않는다.

새 목표음의 실제 앞뒤 지각, 혼합 균형과 진행음 구분의 적절성은 추가 청취 대상이다. 소프트웨어의 좌표·재생 검사 통과를 사람의 청취 평가로 취급하지 않는다.
