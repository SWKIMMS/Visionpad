# 낚시와 음성 청취 확인

2026년 10월 14일 사용자는 첫 영어 음성을 듣고 “소리 괜찮네”라고 평가했다. 현재 음성 설정을 유지한다. 아래는 다음 청취를 위한 순서이며, 아직 수행하지 않은 결과를 미리 표시하지 않는다.

같은 날 후속 의견은 “방향감과 효과음 균형 나쁘지 않아”이며 음성을 조금 낮추면 좋겠다고 했다. 이를 반영해 **Speech volume 기본 85%**를 적용했다. 게임 효과음과 낚시 HRTF는 유지하며 새 음량의 평가는 아직 받지 않았다. 이 일반 평가를 아래 각 방향·기기별 결과를 모두 확인한 것으로 취급하지 않는다.

## 준비

게임을 새로고침하고 스테레오 헤드폰을 연결한다. 두 귀를 모두 사용한다. 게임 창에서 한 번 클릭해 오디오를 활성화하고, 듣기 편한 음량으로 시작한다. 처음 생성하는 문장은 잠깐 준비 시간이 있을 수 있다.

현재 위치에서 오른쪽 이동 버튼을 사용해 낚시 호수로 간다. 이동 순서는 농장 → 집 → 마을 → 광산 → 낚시 호수다. **탐색음만 확인할 때는 낚싯대를 사거나 물을 클릭할 필요가 없다.** 실제 낚시 결과를 확인하려면 먼저 F3를 길게 눌러 진행을 저장하고 상점에서 낚싯대를 구입한다. 구입과 낚시는 기존 규칙대로 골드와 게임 시간을 사용한다.

## 5분 확인 순서

| 순서 | 할 일 | 확인할 내용 |
|---|---|---|
| 1 | 호수 안에서 포인터를 천천히 움직인다. 아직 누르지 않는다. | 물소리가 들리는 쪽으로 이동할 때 소리가 가까워지고, 멀어지면 작아지는가? |
| 2 | 좌우뿐 아니라 위아래로도 이동한다. | 좌우 방향은 구분되는가? 앞뒤가 서로 바뀌거나 같은 방향처럼 들리는가? 실제 방향 혼동은 그대로 기록한다. |
| 3 | `Test guide`를 누른 뒤 포인터로 다시 탐색한다. | 안내와 물소리를 함께 알아들을 수 있는가? 말이 끝나면 음악은 정상 음량으로 돌아오는가? |
| 4 | F1로 지도를 열고 다시 눌러 돌아온다. | 지도에서 탐색 물소리가 멈추고 호수로 돌아오면 복구되는가? 현재 평가 버전의 F4는 선택 버튼이다. |
| 5 | F1로 지도를 열었다가 F1을 다시 누른다. | 지도에서는 물소리가 멈추고 호수로 돌아오면 다시 들리는가? |
| 6 | `Test Rowan`을 누른 뒤 다른 창으로 이동하고 다시 돌아온다. | 창을 떠나면 소리가 멈추는가? 돌아왔을 때 이전 대사와 효과음이 갑자기 재생되지 않는가? 배경음과 호수 탐색음은 현재 화면에 맞게 돌아와야 한다. |
| 7 | 선택 사항: 낚싯대가 있을 때 소리가 가까운 곳에서 한 번 누른다. | 성공하면 물 튀는 소리와 실제 물고기 이름/수량이 들리는가? 실패하면 획득 효과음이 없어야 한다. 누른 채 움직여도 낚시가 반복되면 안 된다. |

음성 음소거와 게임 사운드 음소거는 별도다. `Speech off`로 만들어 둔 음성이 다른 창에 다녀온 뒤에도 꺼져 있는지, `Sound off`로 만들어 둔 소리도 꺼져 있는지 각각 확인할 수 있다. 이후 사용하던 설정으로 되돌린다.

## 게임 효과음 확인

먼저 `output/audio/effects-preview.wav`를 들으면 물·비료·수확·자르기·요리·발걸음·상점 문·거래·채굴·희귀 보상·물고기 획득·심기·완료·행동 불가·낚시 실패 소리를 약 37초에 비교할 수 있다. 영어 라벨 뒤에 각각의 소리가 나온다. 이 파일은 개별 효과음 청취용이고 실제 게임의 입체 방향이나 동시 혼합 확인을 대신하지 않는다.

실제 행동 확인은 진행을 저장한 뒤 수행한다. 구매, 작업과 낚시는 원래 게임 규칙에 따라 재화와 시간을 쓴다.

| 상황 | 기대하는 소리와 확인 사항 |
|---|---|
| 장소 이동, 상점 입장, 거래 | 각각 발걸음, 문, 동전 소리. 같은 행동에서 소리가 이중으로 나지 않는가? |
| 물·비료·수확 | 작업 중 녹음과 목표 통과음, 전체 완료음이 구분되는가? 짧게 눌렀다 떼도 작업음이 들리는가? |
| 자르기와 젓기 | 움직일 때 작업음이 들리고 멈추면 작아지는가? 음성이 끝났다는 이유로 멈춘 작업음이 커지지 않는가? |
| 채굴과 도구 파괴 | 타격, 돌 파괴, 희귀 보상과 도구 파괴가 구분되는가? |
| 불가능한 행동 | 재화나 도구가 없을 때 완료음 대신 행동 불가 소리가 들리는가? |
| 낚시 실패 | 성공의 물 튀는 소리 대신 짧은 실패음이 들리는가? |
| 음성 동시 재생 | 배경음과 효과음이 안내를 가리지 않는가? 수확음과 희귀 획득음은 알아들을 수 있는가? |

현재 효과음 혼합값은 첫 검토용이다. 어떤 행동에서 소리가 너무 작거나 크고, 무엇과 혼동되는지 실제 상황과 함께 기록한다.

## 다른 PC 확인

10월 18일 새 농사/광산 목표음은 별도 청취 대상이다. 물·비료·수확·광산에서 Target cues를 켰다 껐다 비교하고, 가까워질 때 방향/간격을 알아들을 수 있는지와 작업음·통과음·대사를 가리지 않는지 기록한다. 농사 통과음과 연속 채굴 타격의 높낮이로 진행을 구분할 수 있는지도 확인한다. 이 새 소리까지 기존의 긍정적인 낚시 평가에 포함하지 않는다.

다른 PC에는 코드와 `requirements.txt`를 준비하고 README의 모델 다운로드 단계를 실행한다. 모델 및 `.cache/speech/`는 Git에 포함되지 않는다. `Test guide`와 `Test Rowan`을 같은 속도로 재생해 목소리 종류와 발음을 비교한다. 각 PC가 직접 생성하면 합성의 세부 파형이 같다는 보장은 없으므로, 동일 파일의 재생 비교가 필요할 때는 같은 `output/audio/` 샘플 파일을 사용한다. 다른 PC에서 실제 실행하기 전에는 검증 완료로 기록하지 않는다.
