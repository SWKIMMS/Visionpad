# 시연 음성 준비

영어 시스템 음성과 Rowan 음성을 서버에서 미리 생성해 첫 안내의 합성 지연을 줄인다. 현재 목록은 속도 1.0에서 **203문장**(시스템 185, Rowan 18)이다. 고정 문장, Rowan 튜토리얼·조언 분기, 대표 실제 행동/대상/최근 반응을 포함한다. 새로운 수량·가격·반응 조합과 다른 속도는 첫 요청 때 생성할 수 있다.

## 실행

게임 실행기는 새 서버를 시작할 때 자동으로 준비한다. 실행 중인 서버에 별도로 준비할 때는 활성화한 프로젝트 환경에서 다음을 실행한다.

```bash
python tools/prepare_demo.py
# Windows 기본 포트
python tools/prepare_demo.py --server http://127.0.0.1:8003
# 서버 없이 목록만 확인
python tools/prepare_demo.py --list
# 다른 속도의 캐시 준비
python tools/prepare_demo.py --rate 1.2
```

목록 수집은 임시 엔진과 임시 저장을 쓴다. 음성 준비는 실행 중인 서버의 `/api/speech/voices`와 `/api/speech`만 호출하고 플레이 입력을 보내지 않는다. 이미 완성된 WAV는 재사용하고, 실패한 문장은 보고서에 남긴다. 실패 후 재실행해도 성공한 파일을 다시 생성하지 않는다.

기본 보고서는 `output/audio/demo-ready.json`, 음원은 `.cache/speech/`다. 모델과 이 두 경로는 업로드하지 않는다. 다른 PC에서도 설치 도구로 모델을 준비한 뒤 이 명령을 실행한다. 서버 캐시와 별도로 브라우저 다운로드·디코딩 시간은 남는다.

## 음량

**Speech volume**은 시스템/Rowan 목소리에만 적용되며 기본 85%다. 재생 중 조절해도 대사를 다시 시작하거나 생성하지 않는다. **Sound volume**은 최신 팀 설정의 기본 90%이며 게임 효과음과 음악에 적용한다. 두 음량과 **Target cues** 선택은 현재 페이지에서 유지하고 새로고침하면 기본값으로 돌아간다.

## 확인

`test_demo_speech.py`에서 목록 중복, 인물별 목소리, 캐시 재사용, 속도별 구분, 실패 재시도와 음성 API만 호출하는지 검사한다. 실제 합성/브라우저 확인 범위와 팀 전달 순서는 [TEAM_HANDOFF.md](TEAM_HANDOFF.md)에 있다. [청취 순서](LISTENING_CHECK.md)에 따라 음성·효과음 균형은 별도로 확인한다.
